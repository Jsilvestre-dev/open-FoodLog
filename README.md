# Nutrient Tracker App

Native android app that helps keep track of calories and macronutrients consumed. Follows Android's [official architecture guidance](https://pages.github.com/) as closely as possible.

# App Developmental Features
* Jetpack Compose app
* MVVM
* Room db with Paging 3
* Material 3 Expressive
* Utilizes Coroutines and Kotlin Flows
